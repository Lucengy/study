# Apache Ratis 源码学习工作区

本目录用于存放按周拆分的学习任务、实验脚本和学习记录。它不加入根 `pom.xml` 的 `<modules>`，因此不会改变 Apache Ratis 原有构建行为。

## 周目录

| 周次 | 主题 | 入口 |
| --- | --- | --- |
| 第 1 周 | 双端环境、Git 同步、示例入门、三节点实验 | [week-01/README.md](week-01/README.md) |

## 约定

- Windows 是唯一的源码编辑端；Linux 节点只负责拉取已提交代码、构建和运行。
- 每周使用独立分支，如 `study/week-01`；不要直接在 `master` 上做学习改动。
- 每天结束前填写当周 `notes/` 下的记录，并提交一次可回退的 Git commit。
- 学习实验产生的日志、数据和构建产物不要提交到 Git。
